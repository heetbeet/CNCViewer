# Icon artwork

`toolbar-icons.png` contains rasterized [Font Awesome Free 5.15.4](https://github.com/FortAwesome/Font-Awesome/tree/5.15.4) icons by Fonticons, Inc.
The artwork is licensed under [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/).
The SVG silhouettes were resized and combined into a texture atlas. The file icon includes an added plus sign for New File.
[Font Awesome licensing](https://fontawesome.com/license/free).
