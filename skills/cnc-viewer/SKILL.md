---
name: cnc-viewer
description: Inspect and validate CNC G-code with the native CNC Viewer. Use numeric reports, checkpoints, stock sections and focused images to evaluate the resulting cuts.
---

Run `CNC Viewer.exe --help agents` to read the complete inspection guide for your installed version. Use the full executable path in `executable.txt` beside this file if present. From a source checkout, the packaged build is at `output/desktop/CNC Viewer.exe`. In PowerShell, pipe the command to `Out-String` to capture its output.
